# Support

- **Questions** about writing a scoring program client, the protocol or any of the client
  libraries (C#, PHP, Java): please use
  [GitHub Discussions](https://github.com/BridgeSystems/Bridgemate-Data-Connector-Scoring-Program-Client/discussions)
  on this repository — one place for all languages, so answers help everyone.
- **Bugs**: open an issue on the repository of the client concerned
  ([C#](https://github.com/BridgeSystems/Bridgemate-Data-Connector-Scoring-Program-Client/issues) ·
  [PHP](https://github.com/BridgeSystems/Bridgemate-Data-Connector-Scoring-Program-Client-PHP/issues) ·
  [Java](https://github.com/BridgeSystems/Bridgemate-Data-Connector-Scoring-Program-Client-Java/issues)).
  Please include the request/response envelopes (the getting-started samples print them) and the
  Data Connector version (`GET http://localhost:5079/` shows it).
- **Documentation**: start with the
  [developer's guide](https://github.com/BridgeSystems/Bridgemate-Data-Connector-Scoring-Program-Client/blob/master/Documentation/MD/index.md).
